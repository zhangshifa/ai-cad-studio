## 1. 项目背景

### 1.1 为什么做

SolidWorks、Fusion、CATIA 等商业 CAD 价格高、闭源、二次开发受限。其核心价值——“基于特征的参数化建模 + 装配 + 工程图 + 运动/仿真”——其实是一套**可拆解的方法论**，并非不可复现的黑盒。与此同时，2025–2026 年 AI 画图（Text-to-CAD）已从“生成网格玩具”跨越到“生成可编辑的 B-Rep / 参数化特征树”，工程可用性显著提升。

两股趋势叠加，使得打造一款**轻量、可本地部署、可扩展、AI 原生**的开源 CAD 工具成为可行目标。

### 1.2 逆向分析的对象与目标

- **对象**：SolidWorks 的“基本功能”链路（草图、特征、装配、工程图、运动仿真、渲染、基础仿真）。
- **目标**：不是破解/反编译 SolidWorks，而是**抽象其工作流范式**（特征树、配合关系、运动算例、双向关联），据此设计自有工具的功能集合与数据结构。
- **方法**：功能拆解 + 数据模型对齐（B-Rep、特征历史、装配约束图）。

### 1.3 AI 画图趋势（2026 现状要点）

- 主流路线已从“生成 STL/OBJ 三角网格”转向**生成可编辑 B-Rep 与参数化特征树**，可直接进入 CNC / 注塑等制造链路。
- 三类成熟技术路线：
  1. **直接生成几何**（Zoo.dev：自研内核直出 B-Rep，可导出 STEP）；
  2. **代码生成后经内核执行**（AdamCAD / CadQuery / OpenSCAD：输出可 Git 版本控制、可审查的参数化代码）；
  3. **原生 API 调用在特征树里建模**（Fusion Text-to-Command、PTC Onshape FeatureScript AI）。
- 工程级 Agent 普遍采用 **“推理 → 规划 → 编译 → 自修复”** 四阶段闭环（NVIDIA GTC 2026 多智能体框架），生成成功率 >90%。
- 代表产品：Zoo、AdamCAD、DraftAid（2D 出图自动化，省时 up to 90%）、MecAgent（自然语言宏）、Leo AI（草图/规格 → 完整装配体）、SolidWorks 2026 AURA AI 助手。

> 结论：本项目采用**路线 2（代码生成 + 内核执行）** 作为 AI 画图主路径——最契合开源、可审查、可版本化、可本地部署的需求。

## 2. SolidWorks 基本功能逆向分析（能力基线）

| 编号 | 能力域 | 关键能力 | 本项目对应目标 |
|----|------|---------|--------------|
| 2.1 | 草图 Sketch | 2D 轮廓、几何约束、尺寸约束、完全定义、错误诊断 | 二维草图 + 约束求解器 |
| 2.2 | 特征建模 Feature | 拉伸/旋转/扫描/放样/筋/拔模/抽壳/阵列/镜像、曲面 | 参数化特征树建模 |
| 2.3 | 参数化/配置 | 尺寸驱动、配置（同零件多规格）、设计表 | 参数变量 + 配置表 |
| 2.4 | 装配 Assembly | 配合（重合/平行/同轴/距离）、智能配合、干涉检查、爆炸视图、BOM | 装配约束图 + 干涉检测 + BOM |
| 2.5 | 工程图 Drawing | 三视图/剖视/局部放大、双向关联、GB/ISO 标注、BOM 表 | 自动出图（2D 投影 + 标注） |
| 2.6 | 动画/运动仿真 | 关键帧动画、运动算例（马达/弹簧/接触/引力）、碰撞检测 | 运动算例 + 关键帧 + 碰撞 |
| 2.7 | 渲染 Rendering | PhotoView/Visualize 材质/光照/环境 | 实时/离线渲染（PBR） |
| 2.8 | 仿真 Simulation | FEA 约束/载荷/网格/应力位移（进阶） | 路线图中（M5+，可选） |

### 2.1 草图（Sketch）

是一切建模的起点。核心是**轮廓几何 + 约束系统**：

- 几何图元：直线、圆/圆弧、矩形、样条、多边形、槽口。
- 约束：重合、平行、垂直、相切、等长、同心、对称、固定。
- 尺寸：线性、角度、半径/直径、基准尺寸。
- “完全定义”（fully defined）状态判定与冲突诊断。

**逆向要点**：草图 = 一组带约束的 2D 曲线；建模特征引用草图平面与轮廓。本项目需内置轻量 2D 约束求解器（或复用求解库）。

### 2.2 特征建模（Feature-based Modeling）

SolidWorks 的灵魂是**特征树（FeatureManager）**：模型 = 有序特征序列，每个特征引用前序几何。

基础特征：

- 拉伸（Extrude）、旋转（Revolve）；
- 扫描（Sweep）、放样（Loft）；
- 圆角（Fillet）、倒角（Chamfer）、抽壳（Shell）、筋（Rib）、拔模（Draft）；
- 阵列（Linear/Circular Pattern）、镜像（Mirror）；
- 异型孔向导（Hole Wizard）、多实体（Multi-body）。

**逆向要点**：模型可表示为 **“草图 + 特征操作序列”**，这正是 AI 代码生成（CadQuery）天然契合的表达形式。

```python
# AI 生成的示例：带 6 个螺栓孔的法兰（CadQuery）
import cadquery as cq

flange = (
    cq.Workplane("XY")
    .circle(30).extrude(5)              # 主体圆盘（拉伸特征）
    .faces(">Z").workplane()
    .hole(10)                            # 中心孔
    .polarArray(20, 0, 360, 6)           # 圆周阵列 6 个螺栓孔
    .hole(4)
)
```

### 2.3 参数化与配置（Parametric & Configuration）

- 尺寸/关系驱动，改一处全局联动；
- “配置”可在一个零件文件内表达多个规格（如不同孔径螺栓）；
- 设计表（Design Table）用 Excel 驱动多配置。

**逆向要点**：需有**变量系统 + 表达式求值器**，特征参数引用变量。

### 2.4 装配体（Assembly）

- 通过“配合（Mate）”建立零件间约束：重合、平行、同轴、距离、角度；
- 智能配合：齿轮、凸轮、齿条、螺旋；
- 大型装配体：轻化、SpeedPak、干涉检查；
- 爆炸视图、装配序列动画、BOM 输出。

**逆向要点**：装配 = **零件实例 + 约束图**；运动仿真依赖此约束图为运动学基础。

### 2.5 工程图（Drawing）

- 从 3D 自动生成符合 GB/ISO/ANSI 的 2D 图；
- 视图：主/俯/左视图、剖视、局部放大、断裂、交替位置；
- 标注：尺寸公差、形位公差、粗糙度、焊接符号；
- **双向关联**：改 3D 自动更新 2D。

**逆向要点**：工程图 = 3D 模型的**投影 + 标注叠加**，需维护“视图 ↔ 特征”关联。

### 2.6 动画与运动仿真（Animation & Motion Study）

- 关键帧动画（Keyframe）：相机、装配体显示状态、爆炸；
- 运动算例（Motion Study）：马达、弹簧、阻尼、接触、引力，输出运动轨迹；
- 干涉/碰撞检测、机构行程验证。

**逆向要点**：运动仿真 = **约束图 + 驱动源（马达/力）+ 时间积分**；是本项目“动画仿真”模块的核心。

### 2.7 渲染（Rendering）

材质、光照、环境、相机，输出照片级图像（PhotoView 360 / Visualize）。

**逆向要点**：采用 PBR（基于物理的渲染）材质模型，与 WebGL/Three.js 标准对齐。

### 2.8 仿真（Simulation，进阶）

FEA 基础：约束、载荷、网格、应力/位移；结构优化。

**逆向要点**：路线图中远期能力，可对接 CalculiX / Code_Aster 等开源求解器。

## 3. 产品定位与差异化（AI 连接画图）

**一句话定位**：一款“AI 原生、开源可本地部署、可编辑、可制造”的三维 CAD，覆盖 SolidWorks 基本功能主链路，并用自然语言/草图/图片驱动建模与动画。

差异化：

1. **AI 画图优先**：自然语言 → 可编辑参数化模型（不是一次性网格）。
2. **可审查、可版本化**：AI 产出 CadQuery 代码，Git 友好，可 diff、可回滚。
3. **本地优先 + 多端**：本地运行保隐私；Web / 桌面 / 移动（Capacitor）三端同源。
4. **动画仿真内建**：不只是静态建模，内置运动算例与碰撞检测。
5. **开放互操作**：导入/导出 STEP（制造级）、STL（打印）、glTF（Web/AR）。

AI 连接画图的三种入口：

- **自然语言建模**：`“一个外径 60、中心孔 12、6 个均布 M4 螺栓孔的法兰”` → 生成 CadQuery 并执行。
- **草图/图片 → 模型**：上传手绘草图或产品图，识别轮廓与约束，生成参数化特征。
- **对话式修改**：语义理解后定位并修改特征（如“把孔径改大到 14”）。

## 4. 系统架构

### 4.1 总体分层

```
┌─────────────────────────────────────────────┐
│  表现层 (Web / Desktop / Mobile)              │
│  Three.js 视口 + React 交互 + 草图编辑器       │
├─────────────────────────────────────────────┤
│  应用服务层 (Python FastAPI / 本地 http.server) │
│  建模 API · 装配 API · 动画 API · 文件服务      │
├─────────────────────────────────────────────┤
│  AI 层 (DeepSeek + 多智能体)                   │
│  NL→Plan→CadQuery→编译→自修复 闭环            │
├─────────────────────────────────────────────┤
│  几何内核层 (CadQuery + pythonOCC / OpenCascade)│
│  B-Rep 建模 · 网格化(tessellate) · STEP/STL     │
├─────────────────────────────────────────────┤
│  仿真/动画层 (运动学求解 + 碰撞 + 关键帧)        │
│  约束图 → 时间积分 → 轨迹/碰撞报告             │
└─────────────────────────────────────────────┘
```

### 4.2 几何内核选型

- **内核**：OpenCascade（OCC）——开源 B-Rep 几何内核，工业级，支持 STEP。
- **高层 API**：CadQuery（Python，构建于 OCC 之上）——声明式参数化建模，代码即模型，天然适配 AI 生成。
- 视口渲染：OCC 将 B-Rep **网格化（tessellate）** 后交由 Three.js 显示。

> 选型理由：与“AI 代码生成”路线一致；开源、跨平台、可本地部署；STEP 导出满足制造级互操作。

### 4.3 AI 层设计

采用 **“推理 → 规划 → 编译 → 自修复”** 四阶段闭环（对齐 2026 工程级 Agent 范式）：

1. **推理（Reason）**：DeepSeek 解析用户意图，明确零件/装配目标与约束。
2. **规划（Plan）**：拆解为建模步骤（草图 → 特征序列），输出结构化计划。
3. **编译（Compile）**：生成 CadQuery 代码并在沙箱中执行（OCC 内核）。
4. **自修复（Self-repair）**：捕获几何/语法错误，回灌给模型迭代修正，直到成功生成有效 B-Rep。

AI 仅产出**可审查代码**，最终几何由确定性内核生成，保证精度与可制造性。

### 4.4 交付形态

遵循“本地优先、多端同源”原则：

- **Web**：浏览器内建模与查看（Three.js + 本地/云端 Python 服务）。
- **桌面**：Tauri/Electron 封装，或本地 `http.server` 直接打开。
- **移动**：Capacitor 封装 Web，复用同一套前端。
- 数据：本地文件（自有场景 JSON + STEP/STL）+ 浏览器 IndexedDB 缓存。

## 5. 核心功能模块

### 5.1 建模模块（对标 2.1–2.3）

- 2D 草图编辑器（图元 + 约束 + 尺寸）；
- 特征操作：拉伸、旋转、扫描、放样、圆角、倒角、抽壳、阵列、镜像、孔；
- 参数变量系统与表达式求值；
- 特征树管理（增/删/改/重排/抑制）。

### 5.2 装配模块（对标 2.4）

- 零件实例管理；
- 配合约束（重合/平行/同轴/距离/角度）+ 齿轮/凸轮等智能配合；
- 干涉检查、爆炸视图、BOM 表导出。

### 5.3 工程图模块（对标 2.5）

- 从 3D 自动生成三视图/剖视/局部放大；
- GB/ISO 标注样式（尺寸、公差、粗糙度）；
- 与 3D 双向关联更新；
- BOM 表生成。

### 5.4 动画仿真模块（对标 2.6，项目重点）

- **关键帧动画**：相机、显示状态、爆炸动画；
- **运动算例**：马达/弹簧/阻尼/接触/引力驱动，输出运动轨迹；
- **碰撞/干涉检测**：运动过程中实时检测；
- 时间轴编辑器与回放。

> 实现：装配约束图 → 运动学求解（revolute/prismatic 等关节）→ 时间积分；碰撞用包围盒/精确 B-Rep 检测。可选接入 PyBullet 做物理仿真。

### 5.5 AI 画图模块（对标第 3 节）

- 自然语言 → 参数化模型（主入口）；
- 草图/图片 → 模型；
- 对话式特征修改；
- AI 出图辅助（自动标注建议）；
- 全过程可审查、可回滚（代码即历史）。

## 7. 数据格式与互操作

- **自有场景格式**：JSON（特征树 + 参数 + 装配约束 + 动画关键帧），便于版本控制与 AI 编辑。
- **导入/导出**：
  - STEP（.step/.stp）——制造级 B-Rep，主互操作格式；
  - STL / OBJ——3D 打印与网格查看；
  - glTF——Web/AR 展示；
  - SVG/DXF——2D 工程图与草图。
- **兼容性目标**：生成的 STEP 可被 SolidWorks / Fusion 直接打开。

## 10. 风险与开放问题

1. **几何内核复杂度**：OCC 学习曲线陡，曲面/放样高级特征需循序渐进。
2. **AI 生成可靠性**：复杂装配的自然语言理解仍有误差，需强约束校验与自修复。
3. **性能**：大型装配体实时显示与求解需轻化/增量策略。
4. **工程图合规**：GB/ISO 标注细节多，需逐步对齐标准。
5. **FEA 深度**：是否自研或对接开源求解器，待 M5 评估。
