# 📖 AI CAD Studio 使用手册

本手册帮助你完成首次配置、了解各软件适配器的前置条件，并提供可直接使用的 AI 指令示例与常见问题解答。

---

## 1. 首次配置向导

首次启动后，程序会引导你在 **设置对话框** 中完成配置：

1. **选择 AI 提供商**：从下拉列表选择 `OpenAI` / `DeepSeek` / `Moonshot` / `智谱 GLM` / `Anthropic` / `Ollama` / `自定义`。
2. **填写 API Key**：云端提供商需粘贴对应平台的 API Key（Ollama 本地无需 Key）。
3. **填写 Base URL**：使用官方地址或代理/兼容端点；自定义端点填你的服务地址。
4. **选择模型**：填入模型名称（如 `gpt-4o`、`deepseek-chat`、`moonshot-v1-8k` 等）。
5. **测试连接**：点击「测试连接」按钮，确认能与模型正常通信。
6. **保存**：配置写入 `%USERPROFILE%\.ai-cad-studio\config.json`。

> 提示：可在设置中随时切换提供商与模型，无需重启主程序。

## 2. 各软件适配器前置条件

| 适配器 | 前置条件 |
| --- | --- |
| **AutoCAD** | Windows 已安装 AutoCAD 并**处于打开运行状态**；需 `pywin32` 支持 COM 自动化。 |
| **Blender** | 已在设置中配置 `blender.exe` 路径；程序将以 `--background --python` 方式调用。 |
| **FreeCAD** | 已配置 `FreeCADCmd.exe` 路径（通常随 FreeCAD 安装提供）。 |
| **切片器** | 已配置 PrusaSlicer 或 CuraEngine 可执行文件路径。 |
| **打印机** | 二选一：① OctoPrint 已运行并填入地址 + API Key；② 打印机通过串口连接并配置串口名与波特率。 |

> 软件路径配置位于设置对话框的「软件路径」分区，缺失时会提示「找不到软件路径」。

## 4. 常见问题 FAQ

**Q1：AutoCAD COM 连接失败（"无法创建 AutoCAD.Application"）？**
- 确认 AutoCAD 已安装且**正在运行**；以相同 Windows 用户启动本程序；检查 `pywin32` 是否正确安装（`pip show pywin32`）。

**Q2：提示"找不到软件路径"？**
- 在设置对话框中填写对应软件（Blender / FreeCAD / 切片器）的可执行文件完整路径，保存后重试。

**Q3：API 请求超时 / 连接失败？**
- 检查网络与 Base URL 是否正确；确认 API Key 有效且未过期；自定义端点需确认服务可达。Ollama 需本地服务已启动（默认 `http://localhost:11434`）。

**Q4：AI 生成的脚本执行报错？**
- 多为软件版本差异导致。查看聊天区的工具返回信息，将报错反馈给 AI 让其修正后重试；复杂任务可分步下达指令。

**Q5：Agent 循环超过 10 轮未完成任务？**
- 任务可能被强制中断。请简化指令、补充上下文，或拆分成更小的子任务重新提交。

**Q6：打印指令无响应？**
- 检查 OctoPrint 地址/Key 是否正确，或串口名与波特率是否匹配；确认打印机已联机且未处于报错状态。

**Q7：配置如何备份/迁移？**
- 复制 `%USERPROFILE%\.ai-cad-studio\config.json` 即可；注意其中含 API Key，请妥善保密。
